# 공개 준비 검증 — 2026-10-08

## 판정과 범위

실험적 개발 포트폴리오로 게시할 소스와 시연 자료를 준비했습니다.
코드 검증, 합성 영상 렌더링, 배포용 wheel 설치와 공개 ZIP 생성을 확인했습니다.
GitHub 게시, 커밋, 푸시, 원격 저장소 생성은 수행하지 않았습니다.
오픈소스 라이선스는 작성자의 선택 전까지 미지정 상태를 유지합니다.

## 이번에 수정한 문제

| 문제 | 변경과 검증 |
|---|---|
| `doctor`가 렌더 준비 여부를 확인하지 않음 | 실제 자막 렌더러 탐색을 재사용. libass 필터가 없으면 JSON 오류와 종료 코드 2 반환. 성공과 실패 경로 검사 |
| 입력 검증 실패 후 export 경로를 재사용할 수 없음 | 임시 폴더에서 교환 자료를 검증한 뒤 출력 경로 생성. 잘못된 run과 용어집은 출력 없이 실패. 같은 경로 재시도와 기존 파일 보존 검사 |
| 패키징이 Git에 의존하고 LICENSE를 제외함 | 명시한 소스 폴더와 파일 목록으로 탐색. Git 없이 동작. LICENSE와 검토한 공개 이미지 포함, 환경과 비공개 파일 거부 |
| 환경 차이로 VFR 테스트가 실패함 | FFmpeg 7.1의 합성 Matroska 영상은 실제 길이가 9.96초였음. 고정 10초 대신 측정 길이에 계획을 결합. 컷으로 정확히 96프레임 제거되는지와 오디오/영상 동기화 검사 유지 |
| 좁은 UI에서 후보 설명이 여러 열로 분리됨 | 시간과 이유를 같은 설명 영역에 배치. 실제 브라우저에서 확인하고 스크린샷 갱신 |
| 저장소 경계가 상위 Downloads였음 | 프로젝트 폴더에 독립 Git 저장소 초기화. 상위 저장소와 파일은 수정하지 않음. 커밋과 원격은 없음 |
| 시연 자료와 공개 안내 부족 | 합성 편집 전후 GIF, 실제 UI 스크린샷, 설치 진단과 게시 안내 추가. README를 결과와 설계 판단 중심으로 정리 |

CI는 Linux/Python 3.12의 ASR 포함·미포함 설정과 macOS/Python 3.13 설정을 검사하도록 구성했습니다.
패키지 일관성, `doctor`, 코드 스타일, 테스트, 합성 렌더링과 공개 ZIP 생성을 실행합니다.
GitHub Actions 실행 성공은 게시 후 실제 결과를 확인해야 합니다.

## 이번에 실행한 검증

환경: macOS Apple Silicon, Python 3.13.12, FFmpeg 7.1, ffprobe 8.0.1,
Pydantic 2.13.5, Ruff 0.16.10. ASR 포함 환경의 faster-whisper는 1.2.1입니다.

| 검사 | 실제 결과 |
|---|---|
| 저장소 `.venv`, ASR 포함 전체 테스트 | **97 passed** |
| ASR 미포함 새 환경, 배포용 wheel 설치 후 전체 테스트 | **96 passed, 1 skipped** |
| Ruff lint와 format check | 통과 |
| `pip check` | 의존성 충돌 없음 |
| 합성 데모 | 10.00초 → 8.77초, 미승인 MP4 생성 |
| 실제 검토 UI | 합성 계획 불러오기, 미리보기, 승인 버튼 활성화와 승인 전 최종 출력 차단 확인 |
| 공개 ZIP | 원시 미디어, 작업 결과, 가상환경과 Git 이력 제외. 이미지 두 개 포함. 무결성 확인 |

ASR 미포함 환경에서는 모델 캐시 오류 검사 하나를 건너뜁니다.
ASR 패키지가 없을 때의 실제 CLI 오류와 원본 보존은 별도 subprocess로 검사합니다.
모델 가중치를 다운로드하거나 실제 음성 인식과 LLM 판단 품질을 평가한 것은 아닙니다.

초기 시스템 FFmpeg 8.0.1에는 자막 필터가 없어 렌더 관련 테스트와 합성 데모가 실패했습니다.
시스템 설치와 전역 설정을 변경하지 않고, PyPI `imageio-ffmpeg`의 FFmpeg 7.1을
프로젝트 `.venv/bin/ffmpeg`에 연결해 검증했습니다. 이는 로컬 검증 도구이며
프로젝트 런타임 의존성이나 공개 ZIP에 추가하지 않았습니다.
새 사용자의 설치 경로는 README의 libass 지원 FFmpeg 설치입니다.

## 공개 자료의 출처

- GIF: 저장소의 합성 영상, 직접 작성한 전사와 응답 JSON으로 생성한 원본/초안 비교.
  자막 크기는 비교 GIF의 가독성을 위해 확대했습니다.
- UI PNG: 합성 자료를 불러온 실제 브라우저 화면. 최종 승인하지 않았습니다.
- 실제 비공개 영상: 기존 개발 사례의 집계 기록만 문서에 유지합니다. 원본과 전사는 포함하지 않습니다.

GIF를 다시 만들려면 다음을 실행합니다. FFmpeg의 `drawtext` 필터도 필요합니다.

```sh
python scripts/demo_agent.py --output work/new-showcase
python scripts/make_showcase.py --demo work/new-showcase --output work/demo-before-after.gif
```

공개 이미지 이름은 패키징 목록에 명시되어 있습니다. 새 이미지는 내용을 검토한 뒤 목록을 갱신하세요.
