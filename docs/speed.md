# M5: 승인한 대기 구간 배속

M4 계획에 사용자가 지정한 대기 구간을 추가하고, 미리 본 뒤 승인합니다. 로딩 화면을
자동 인식하지 않으며, 지정한 구간도 승인 전에는 적용되지 않습니다. ASR·번역·외부
서비스 호출 없이 처리합니다.

## 배속 후보 추가

```bash
video-agent speed-add work/edit-plan.json \
  --start 2 --end 6 --rate 2 --audio mute --output work/speed-plan.json
```

시간은 **원본 영상의 초 단위**입니다. 컷이 적용된 결과 영상 시간이 아닙니다.
시작·종료는 지정 범위 안쪽의 출력 CFR 프레임으로 맞춥니다. 예시는 2–6초를 2배속으로
지정합니다. 실제 영상에서 기다리는 구간에 맞게 값을 바꾸세요.

- 배속은 1보다 크고 4 이하입니다. 슬로모션은 지원하지 않습니다.
- 기본 `mute`: 배속 구간의 소리만 음소거합니다. 주변 구간은 원래 소리를 유지합니다.
- `tempo`: 피치를 유지하며 해당 구간의 소리를 빠르게 재생합니다. 음악·환경음 품질은
  미리보기에서 확인하세요. 음성 보호를 우회하는 옵션이 아닙니다.
- 발화 또는 자막과 겹치면 거부합니다. 컷과 배속의 중복 적용도 승인 단계에서 거부합니다.
- 전사를 생략하면 알려진 발화 보호 정보가 없습니다. 검토 요약의
  `speech_protection_available`을 확인하고 구간을 직접 들어보세요.

후보를 더 추가하려면 새 계획을 입력으로 넣고 다른 출력 파일을 지정합니다.
기존 파일은 덮어쓰지 않습니다. 배속 후보끼리 겹치면 거부합니다.

## 검토·미리보기·승인

```bash
video-agent review work/speed-plan.json --cuts 1 --speeds 1
video-agent preview work/speed-plan.json --cuts 1 --speeds 1 --output work/speed-preview
video-agent approve work/speed-plan.json --cuts 1 --speeds 1 --output work/speed-approved.json
video-agent render work/speed-approved.json --output work/speed-final
```

`--cuts`와 `--speeds`는 각각 다른 ID 목록입니다. 실제 계획의 ID를 확인한 뒤 선택합니다.
예시에서 컷 1이 불필요하면 `--cuts 1`을 생략합니다. 각 명령에서 명시한 항목만 선택하며
나머지는 적용하지 않습니다. 이전 명령의 선택을 자동 기억하지 않습니다.

검토 요약의 `execution_spans`에 원본→출력 프레임 범위, 요청 배속, 실제 적용 배속,
오디오 정책을 표시합니다. 예를 들어 100프레임을 1.5배속으로 줄이면 67프레임을 출력하므로
실제 배속은 약 1.49254입니다. 프레임 반올림에 맞춰 영상과 오디오 길이를 일치시키며,
출력 프레임 1개도 절약하지 못하는 구간은 거부합니다.

뒤에 나오는 자막은 컷으로 삭제한 시간과 배속으로 줄어든 시간을 모두 반영합니다.
발화·자막 자체에 배속을 걸지 않으므로 기존 설명은 정상 속도로 유지됩니다.

## 결과·호환성

M4와 같이 `edited.mp4`, 자막이 입혀진 `preview.mp4`, 출력 시간 기준 SRT와 실행 계획을
만듭니다. `removed_frames`는 컷 삭제량, `speed_saved_frames`는 배속 절감량입니다.
렌더러는 영상 길이뿐 아니라 오디오 길이도 실행 계획과 맞는지 확인합니다.

배속 계획은 스키마 1.1을 사용합니다. 기존 1.0 컷 계획과 승인 파일은 계속 읽고 실행할
수 있습니다. 승인 후 배속·범위·오디오 정책이 바뀌면 다시 검토·승인해야 합니다.
앱 구현이 변경된 뒤에는 이전 렌더 캐시를 억지로 재사용하지 말고 새 출력 폴더를 씁니다.

## 검증과 남은 범위

합성 10초 영상에서 0.2–1.8초를 삭제하고, 원본 2–6초에 2배속을 적용해 6.4초 영상을
만들었습니다. 원본 5초 장면 전환은 1.9초, 원본 7–8초 자막은 3.4–4.4초로 이동했습니다.
예제는 `work/m5-demo/final/preview.mp4`입니다.

자동 테스트는 음소거, 피치 유지, 1.5·2·3.5·4배속, 오디오 없는 영상, 프레임 반올림,
컷 충돌, 발화 보호, 승인 변경 감지와 기존 승인 파일 호환성을 확인합니다. 실제 고객
데모의 대기 구간 판단·음질 평가는 아직 하지 않았습니다. 자동 로딩 감지, 속도 램프,
오디오 크로스페이드, CapCut 프로젝트 연동은 이 단계에 포함되지 않습니다.
