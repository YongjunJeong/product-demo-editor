# 로컬 검토 화면과 작업 복구

```bash
cd /path/to/product-demo-editor
source .venv/bin/activate
video-agent ui
```

터미널에 표시된 전체 주소(`#` 뒤 세션 키 포함)를 브라우저에서 엽니다.
기본 포트는 8765이며 `--port 8766`으로 바꿀 수 있습니다.
`--work-dir work/ui`는 생성할 작업 폴더의 기준 경로입니다.
서버는 127.0.0.1에만 연결되며 외부 CDN, 번역 API, 원격 추론을 사용하지 않습니다.
단일 사용자·단일 편집 탭 용도입니다. 터미널의 Ctrl+C로 종료하며 실행 중인 작업은
완료될 때까지 기다립니다. 브라우저를 닫는 것만으로 서버가 종료되지는 않습니다.

## 화면에서 작업하기

1. **영상 불러오기**: **영상 파일 선택**으로 로컬 폴더를 탐색하거나 원본의 전체 경로를 입력하고 분석합니다. 음성이 없는 합성 영상은
   한국어 음성 인식을 해제할 수 있습니다. 음성 인식 모델은 CLI에서 미리 준비합니다.
2. **영어 자막**: 한국어 발화 옆에 번역을 입력하고 초안을 저장합니다. 자동 번역은
   수행하지 않습니다. 한국어 전사 교정과 용어집 설정은 기존 CLI 워크플로를 사용합니다.
3. **편집 후보**: 삭제할 무음 후보를 체크합니다. 배속은 원본 기준 시작·끝·배율·음성
   정책으로 후보를 추가한 뒤 체크합니다. 발화나 자막과 겹치는 편집은 차단합니다.
4. **자막 검토**: 문구를 수정하고 미리보기를 생성합니다. 컷·배속·문구가 반영된
   영상과 원본을 각각 재생하고 편집 후 길이를 비교합니다.
5. **승인**: 해당 미리보기 버전을 명시적으로 승인합니다. 문구나 선택을 바꾸면
   미리보기를 다시 생성해야 승인·최종 렌더를 진행할 수 있습니다.
6. **최종 영상 생성 → CapCut 파일 내보내기**: 완료한 폴더 경로가 화면에 표시됩니다.
   CapCut 가져오기 순서는 [파일 교환 안내](capcut.md)를 참고하세요.

영상 파일 선택은 로컬 경로를 고르는 방식이며 영상 복사나 업로드를 하지 않습니다. 분석·렌더 같은 긴 작업은 한 번에
하나만 실행하고 처리 중 입력을 잠급니다. 오류는 화면에 표시하며 원본은 변경하지
않습니다. 각 작업은 고유 폴더에 저장되고 기존 승인이나 렌더를 덮어쓰지 않습니다.

## 이어서 검토하기

분석·계획 불러오기로 만든 작업은 **저장된 작업** 목록에 남습니다. 서버를 같은
`--work-dir`로 다시 실행하면 마지막 작업을 자동 복구하며, 목록의 **이어서 열기**로
다른 작업을 선택할 수 있습니다. 원본·계획·미리보기·승인·최종 결과를 검사하고
변경이나 누락이 있으면 승인을 해제하고 다시 검토하도록 안내합니다.

문구·컷·배속 선택·번역을 아직 미리보기로 저장하지 않았다면 **입력 초안 저장**을
누르세요. 저장한 초안은 재시작 후에도 복구됩니다. **저장하지 않은 입력은
새로고침·작업 전환·서버 종료 때 사라집니다.** 입력 초안 저장은 편집 승인이 아닙니다.
M7 이전에 만든 파일은 **기존 작업 이어서 검토**로 불러오면 새 목록에 등록됩니다.

진행 상태에는 현재 분석/렌더 단계와 경과 시간을 표시합니다. 처리 백분율이나
완료 예상 시간은 제공하지 않습니다. 실패하거나 서버 종료로 중단된 작업에는
**실패한 작업 재시도** 버튼이 나타납니다. 원인을 해결한 뒤 누르면 동일 입력으로
새 출력 폴더에 다시 실행합니다. 완료된 중간 단계를 자동 재사용하는 UI 재시도는
아니며, 기존 CLI의 검증된 resume 기능은 계속 사용할 수 있습니다.

작업 상태는 `--work-dir` 아래 `sessions/`에 기록됩니다. 세션 키는 저장하지 않아
재시작 후 새 주소로 접속해야 합니다. 같은 작업 폴더로 서버 여러 개를 동시에 실행하지
마세요. 손상된 기록은 목록에 표시하고 원본과 생성된 편집 파일은 보존합니다.

이 버전은 전체 타임라인 편집기가 아닙니다. 드래그 편집, 자막 시간 조절, 시각 기반
대기 감지, 자동 번역과 작업 취소는 아직 지원하지 않습니다.
브라우저가 원본 코덱을 재생하지 못하면 FFmpeg가 생성한 MP4 미리보기로 확인하세요.
HDR·장시간 4K·실제 제품 데모 품질은 별도 검증이 필요합니다.

## 로컬 접근 경계

실행마다 새 세션 키를 발급하며 API와 영상 접근에 키가 필요합니다. Host·Origin을
검사해 다른 웹사이트에서의 호출을 거부합니다. 임의 파일 경로를 URL로 제공하지 않고
현재 작업에 등록한 미디어만 읽습니다. 영상 탐색을 위해 byte-range 요청을 지원합니다.
이는 신뢰할 수 있는 로컬 사용자의 도구이며 공용 서버 배포용 인증 시스템이 아닙니다.

에이전트 스킬로 만든 `plan.json`은 **계획 불러오기**로 여세요. 번역 초안과 설명이 붙은 삭제·배속 후보를 검토하며, 선택한 제안만 미리보기에 적용됩니다.
